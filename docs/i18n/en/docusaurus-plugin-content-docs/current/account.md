# Account Management

Eidolon uses a simple username + password authentication system — no email verification required. Register and start using immediately.

---

## Register an Account

1. Open Eidolon and click the **"Register"** tab on the login page
2. Fill in the registration form:

| Field | Requirements | Description |
|--------|-------------|-------------|
| Username | 3–64 chars, letters/numbers/underscores/hyphens | Used for login, cannot be changed |
| Nickname | Any text | The name AI uses to address you |
| Password | At least 8 characters | Include letters and numbers recommended |
| Confirm Password | Must match password | Prevents typos |
| Invite Code | Required during beta | Get from the community |
| Gender | Male/Female | Helps AI understand you better |

3. Click **"Create Account & Enter"** — you'll be automatically logged in after registration

:::info About Invite Codes
Eidolon is currently in beta testing and requires an invite code to register. Invite codes are distributed by community admins or content creators. Join the official community to get one.
:::

---

## Login

1. Open Eidolon — the login page is shown by default
2. Enter your username and password
3. Click **"Login & Enter"**

After logging in, the system automatically syncs your conversation history, memories, and personalization settings.

---

## Change Password

1. Click the user menu in the title bar (top right)
2. Select **"Change Password"**
3. Enter your current password and new password
4. Click **"Confirm Change"**

:::tip Security Tips
- Don't reuse passwords from other sites
- Password length of 12+ characters recommended
- Change your password regularly
:::

---

## Log Out

1. Click the user menu in the title bar
2. Select **"Log Out"**
3. Confirm the logout

After logging out, locally cached messages are cleared, but cloud data is unaffected. Logging back in will restore everything automatically.

---

## Switch Accounts

Eidolon supports switching between multiple accounts on the same device:

1. Log out of the current account
2. Enter a different username and password on the login page
3. Log in

Each account has its own conversation space, memories, and settings. When you switch accounts, AI interacts with you as the corresponding account identity.

---

## Data Security

- Your conversations and memories are stored on cloud servers with encrypted transmission
- Local cache is only available while logged in
- Logging out clears the local cache
- Logging in on different devices with the same account automatically syncs data
