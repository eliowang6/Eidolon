# Themes & Appearance

Eidolon offers multiple carefully designed interface themes, each with a unique visual style and atmosphere. Switch themes anytime based on your mood and preference.

---

## Switching Themes

1. Go to **Settings → Appearance → Interface Theme**
2. Browse available themes
3. Click to select a theme you like
4. The interface changes immediately — no restart needed

---

## Font Settings

Each theme comes with a matching font style, but you can manually switch:

1. Go to **Settings → Appearance → Interface Font**
2. Select a font scheme

### Available Fonts

| Font | Style |
|------|-------|
| Follow Theme | Let each theme keep its original tone and rhythm |
| Atelier Serif | Like handwritten letters, brass lamps, and wooden table edges — stable, gentle |
| Harbor Notes | Sea breeze, ship logs, and polished brass — lighter, more breathing room |
| Signal Sans | Like a console, screen glow, and clear commands — sharp but not loud |
| Editorial Calm | Magazine margins and whitespace — for more restrained, tidy reading |
| Salon Contrast | For more lavish themes — like velvet, wine glasses, and slowed conversation |

---

## Ambient Atmosphere

Themes change more than just colors — they also affect:

- **Background ambiance**: Each theme has unique gradients and light effects
- **Fog effect**: Soft background blur for enhanced depth
- **Character lighting**: The character model's lighting changes with the theme

---

## Tips

- Choose themes based on time of day: fresh ones for daytime, warm ones for evening
- Try different theme + font combinations for the best reading experience
- Theme switching doesn't affect conversations or data
