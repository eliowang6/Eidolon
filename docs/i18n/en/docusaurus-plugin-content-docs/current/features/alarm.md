# Alarms & Reminders

Eidolon's alarm feature lets AI remind you of important things at specified times. Unlike ordinary alarms, AI delivers reminders conversationally and gently.

---

## Creating an Alarm

1. Go to **Settings → Alarms**
2. Click **"Add Alarm"**
3. Fill in the alarm details:

| Field | Description | Example |
|-------|-------------|---------|
| Title | Alarm name | Wake up |
| Description | Detailed note (optional) | Time to get ready to go |
| Time | Trigger time | 07:30 |
| Repeat | Recurrence | Once / Daily / Weekly / Monthly |

4. Save

---

## Repeat Options

| Option | Description |
|--------|-------------|
| Once | Rings once, then auto-disables |
| Daily | Rings at the same time every day |
| Weekly | Rings at the same time every week |
| Monthly | Rings at the same time every month |

---

## Managing Alarms

### View Alarm List

In **Settings → Alarms**, see all alarms with:

- Title and description
- Trigger time
- Repeat setting
- Enabled/disabled status

### Enable/Disable

- Toggle the switch next to an alarm to temporarily disable it without deleting
- Disabled alarms won't trigger but can be re-enabled anytime

### Edit an Alarm

Tap an alarm entry to enter edit mode, modify any field, and save.

### Delete an Alarm

Remove unwanted alarms from the alarm list.

---

## Alarm Triggering

When an alarm triggers:

1. The system sends a notification (desktop/mobile)
2. AI proactively reminds you in the conversation
3. One-time alarms are automatically marked as triggered

---

## Notification Permissions

Alarms require notification permissions to work properly:

- **Desktop**: System will request notification permission on first use
- **Android**: Make sure Eidolon's notification permission is enabled
- **Web**: Browser must allow notifications

If alarms aren't triggering, check that notification permissions have been granted.

---

## Tips

- Use repeating alarms to build daily routines (e.g. wake up at 7:30 every day)
- Add descriptions to alarms for more targeted AI reminders
- Combine with to-dos to never miss important tasks
