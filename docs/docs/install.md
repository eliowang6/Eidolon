# 安装指南

Sholarel 提供 **Windows 桌面端**、**Android 手机端** 和 **网页端** 三种使用方式。下面详细介绍每种平台的安装步骤。

---

## Windows 桌面端

### 系统要求

- Windows 10 版本 1803 或更高
- 4 GB 以上内存
- 600 MB 以上可用磁盘空间（MSI 安装包 232,304,640 字节，约 222 MB；装完后程序目录约 252 MB）
- 稳定的网络连接

### 安装步骤

1. 前往 [官网下载页](https://sholarel.instarmony.com/download)
2. 下载最新版 `.msi` 安装包
3. 双击下载的 `.msi` 文件
4. 如果 Windows 弹出"已保护你的电脑"提示：
   - 点击 **「更多信息」**
   - 点击 **「仍要运行」**
5. 按照安装向导完成安装
6. 安装完成后，从桌面或开始菜单启动 Sholarel

### 首次启动

首次启动时，Windows 可能会弹出防火墙提示，请选择 **「允许访问」**，否则 Sholarel 无法连接服务器。

### 桌面端独有功能

桌面端提供以下其他平台没有的功能：

| 功能 | 说明 |
|------|------|
| 悬浮窗模式 | 角色以小窗口悬浮在桌面，随时可见 |
| 开机自启动 | 系统启动时自动运行 Sholarel |
| 专注模式全屏 | 专注时窗口自动扩展为伪全屏 |
| 屏幕截图/录制 | 在聊天中直接截屏或录屏发送给 AI |

## Android 手机端

### 系统要求

- Android 7.0 (API 24) 或更高
- 仅支持 64 位（arm64-v8a）设备
- 3 GB 以上内存
- 700 MB 以上可用存储空间（APK 安装包 270,646,006 字节，约 258 MB；安装时系统还会保留一份安装副本）

### 安装步骤

1. 在 [官网下载页](https://sholarel.instarmony.com/download) 下载 `.apk` 文件
2. 在手机上打开下载的 APK 文件
3. 如果提示"未知来源应用"：
   - 前往 **设置 → 安全** 
   - 开启 **「允许安装未知来源应用」**
4. 等待安装完成
5. 在应用列表中找到 Sholarel 图标，点击打开

### 权限说明

Sholarel 手机端可能请求以下权限：

| 权限 | 用途 |
|------|------|
| 麦克风 | 语音通话、语音消息 |
| 摄像头 | 视频通话、拍照发送 |
| 通知 | 闹钟提醒、消息通知 |
| 应用使用时长 | 每日总结（需单独授权） |

:::tip 应用使用时长授权
在 Android 上，如果你想让 Sholarel 的每日总结更准确，需要在设置中额外授权"应用使用时长访问"权限。路径：**设置 → 应用 → Sholarel → 使用时长访问**。
:::

## 更新

### 桌面端更新

Sholarel 桌面端支持自动更新。当有新版本时，启动后会弹出更新提示，点击确认即可自动下载安装。

如果自动更新失败，可以手动前往 [官网下载页](https://sholarel.instarmony.com/download) 下载最新安装包覆盖安装。

### 手机端更新

手机端需手动下载新版 APK 覆盖安装。安装后所有数据和设置都会保留。

---

## 卸载

### Windows

- **设置 → 应用 → Sholarel → 卸载**
- 或在安装目录运行卸载程序

### Android

- **设置 → 应用 → Sholarel → 卸载**

:::caution 卸载注意
卸载不会影响你的账号和云端数据。重新安装后登录同一账号，对话历史和设置会自动恢复。
:::
