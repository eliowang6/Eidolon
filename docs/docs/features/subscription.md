# 订阅、回响与应急提灯

Sholarel 的付费订阅以 **31 天**为一个周期。档位主要决定默认知己模型、每周期回响额度，以及可用的高级能力。

## 回响额度

回响是聊天、语音、图片、视频、工具调用和后台陪伴能力的统一计量单位。不同操作消耗不同，周期回响先用，周期回响耗尽后才会使用已购买的溯时星露。

### 典型操作消耗倍率

下表基于近 30 天生产数据，以一次普通文字聊天为 1x，取 P50 中位数估算：

| 操作 | 消耗倍率 |
|---|---:|
| 普通文字聊天 | 1x |
| 语音消息 | 约 1.3x |
| 近期多图聊天 | 约 2x |
| 单条语音合成 | 约 0.5x |
| 联网查询 | 约 12x |
| 视频通话 | 约 14.5x/分钟 |
| 语音通话 | 约 2.9x/分钟 |

即时总结、场记、记忆反思等后台功能按实际发生计入总额度：即时总结与场记通常各约占总消耗 5%，昨日总结／日记约 0.6%，记忆反思约 2%。

<p style="color: var(--ifm-color-emphasis-600); font-size: 0.85em; margin-top: -0.5rem;">根据 3.0 公测后半个月用户平均使用情况，在默认的一档心智预设下的估算结果，使用其它档位或更改高级微调选项可能有少量误差。</p>

额度使用情况可在 **设置 → 订阅与额度** 查看。界面只展示使用比例与预计续航，不展示底层供应商价格。

## 应急提灯

有效付费订阅把周期回响与星露都用完后，会进入明确可见的「应急提灯」：

- 每个自然日 10 轮纯文字轻聊，次日 **04:00（Asia/Shanghai）** 恢复
- 纯粹陪伴模式下为每日 5 轮
- 看图、语音、表情包、图片视频、附件、通话、工具调用与长记忆检索均不可用
- 普通长期记忆仍可使用，但不会发起反思、独立记忆整理等会额外消耗模型的侧车
- 即时总结与昨日总结各最多 1 次，并计入当日提灯轮次
- 主动消息最多 1 次，同样计入提灯轮次
- 主动通知与邮件推送不受影响
- 内心独白和导演过程以锁定状态展示，不向用户展开
- 总结不能发布为动态，也不能触发 AI 评论

提灯请求只会使用固定的两道轻量文字模型回退链。若两跳都失败，本轮不会偷偷退回普通模型，也不会生成伪装成成功的 SAFE 回复。

订阅到期、账户停用或从未订阅时不会发放提灯。补充星露或升级订阅可立即恢复完整能力。

## 纯粹陪伴模式

用户可在设置中主动开启「纯粹陪伴模式（省流）」：

- 保留普通文字聊天、长期记忆查询、即时总结、昨日总结、主动消息、通知、邮件、天气与位置感知
- 关闭导演、推荐回复、非必要记忆反思、AI 日记、自动联网研究等用户不可见的后台任务
- 关闭语音、表情包、图片、视频、附件与通话；AI 不会读取历史多媒体
- 每日应急提灯轮次降为 5 轮

已配置的模型与功能偏好不会被删除；退出纯粹陪伴模式后恢复原有设置。

星露不会提升订阅档位，也不能单独解锁高于当前档位的模型或功能。

## 切换与升级

进入 **设置 → 订阅与额度** 可查看当前档位、剩余天数和可用回响。升级时，当前档位未使用部分按剩余天数折抵，再补差价；新档位立即生效，并叠加新的 31 天周期。

## 常见问题

### 额度用完了怎么办？

有效付费订阅会保留每日应急提灯。补充溯时星露或升级订阅可立即恢复完整陪伴；也可以等待次日 04:00 恢复提灯轮次。

### 降级后数据会丢失吗？

降级或到期后，超出当前权限的功能不可用，但不会自动删除全部历史数据。不同数据的保留规则不同，请在换设备、卸载或长期停用前备份重要内容。

### 是否提供免费试用？

当前不提供会解锁完整付费能力的免费试用。下载客户端免费；订阅页会明确展示首期价与常规续费价。
