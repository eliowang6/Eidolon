# 表情包与贴纸

Eidolon 支持丰富的表情和贴纸功能，让对话更生动有趣。你可以搜索海量表情包，也可以上传自己的专属贴纸。

---

## 常用表情

输入框上方有常用表情面板，包含 40 个精选 emoji：

😊 😂 🤣 😍 🥰 😘 😋 😜 😎 🤔 😭 😱 😡 🥳 😴 🥺 🙄 👋 👍 👎 🙌 👏 🤝 ❤️ 🧡 💛 💚 💙 💜 🖤 ✨ 🌟 🔥 🌈 🌸 🐱 🐶 🍕 🎉 🎁

点击即可插入到消息中。

---

## 搜索表情包

Eidolon 内置表情包搜索功能，输入关键词即可找到匹配的表情：

1. 点击输入框的 **表情** 按钮
2. 在搜索框中输入关键词（如"开心"、"猫猫"、"加油"）
3. 系统搜索匹配的表情包
4. 点击表情包即可发送

### 搜索技巧

- 使用具体关键词效果更好："大笑"比"笑"更精准
- 可以组合关键词："猫 生气"
- AI 也会根据对话内容自动推荐表情

## 自定义贴纸

你可以上传自己的图片或 GIF 作为贴纸，随时在聊天中使用。

### 上传贴纸

1. 点击表情面板中的 **「上传表情」** 按钮
2. 选择图片或 GIF 文件
3. 等待上传完成
4. 上传成功后出现在自定义表情面板中

### 贴纸限制

| 限制项 | 要求 |
|--------|------|
| 文件大小 | 不超过 5 MB |
| 图片尺寸 | 不超过 1024×1024 |
| 数量上限 | 最多 50 个自定义贴纸 |
| 格式 | JPG、PNG、GIF |

### 管理贴纸

- 在自定义表情面板中长按/右键点击贴纸可以删除
- 删除后不可恢复，请谨慎操作

---

## AI 发送表情

AI 也会在对话中发送表情包：

- AI 会根据对话氛围选择合适的表情
- AI 发送的表情基于你的角色模型参考图生成
- 你可以在设置中自定义表情参考图

### 表情参考图

AI 生成表情时需要一张参考图来确定风格：

- **默认**：自动从当前 VRM 模型截图生成
- **自定义**：在 **设置 → 偏好 → 使用自定义参考图** 中上传你自己的参考图

:::tip
使用自定义参考图可以让 AI 生成的表情更符合你想要的风格。
:::
