# 长期记忆

Eidolon 的 AI 拥有 **长期记忆** 能力——它会自动记住你分享过的重要信息，跨越会话保持对你的了解。越聊越懂你，不是一句空话。

---

## 记忆如何工作

1. **自动识别**：AI 在对话中自动识别值得记住的信息
2. **存储记忆**：重要信息被保存到长期记忆库
3. **回忆应用**：后续对话中 AI 会参考记忆来理解你
4. **持续积累**：随着交流增多，AI 对你的了解越来越深

---

## AI 会记住什么

| 类型 | 示例 |
|------|------|
| 个人信息 | 名字、生日、性别 |
| 喜好偏好 | 最喜欢的食物、电影类型 |
| 日常习惯 | 作息时间、运动习惯 |
| 重要事件 | 考试日期、旅行计划 |
| 关系信息 | 朋友名字、家庭情况 |
| 情感状态 | 最近的心情变化 |

---

## 查看记忆

1. 点击导航栏的 **「记忆」**
2. 浏览 AI 记住的所有信息
3. 每条记忆显示：
   - 你说的话
   - AI 的回应
   - 记忆时间
   - 是否包含图片/语音

### 搜索记忆

在记忆页面，你可以搜索特定内容：

- 输入关键词搜索相关记忆
- 按时间浏览记忆
- 查看包含图片或语音的记忆

---

## 记忆与订阅

不同订阅等级的记忆能力不同：

| 等级 | 记忆持久化 | 记忆搜索 |
|------|-----------|----------|
| Awakening | 有限 | ❌ |
| Presence | ✓ | ❌ |
| Perception | ✓ | ✓ |
| Genesis | ✓ | ✓ |

- **记忆持久化**：对话结束后记忆是否保留
- **记忆搜索**：是否支持搜索历史记忆

---

## "我们"页面

**「我们」** 页面展示了你和 AI 之间的共同记忆和关系：

| 内容 | 说明 |
|------|------|
| 在一起天数 | 你和 AI 相识的天数 |
| 聊过的句子数 | 总对话数量 |
| 今天聊的句子 | 今日对话数量 |
| 心情记录数 | 累计心情记录 |
| 情绪轨迹 | 最近的心情变化曲线 |
| 共同主题 | 你们常聊的话题 |
| 成就 | 交流里程碑 |

---

## 小贴士

- 主动告诉 AI 你的重要信息，帮助它更好地了解你
- 定期查看记忆页面，确认 AI 记住的信息是否准确
- 如果 AI 记错了，直接告诉它正确信息，它会更新记忆
