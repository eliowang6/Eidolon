# 设置与偏好

Eidolon 的设置页面集中了所有个性化配置选项，你可以按照自己的习惯和需求调整应用行为。进入 **设置** 页面即可查看和调整所有选项。

---

## 外观设置

外观设置包括界面主题、字体、角色模型和头像，详见以下专题文档：

- [主题与外观](/features/theme) — 主题、字体、环境氛围
- [角色模型](/features/avatar) — VRM/Live2D 模型、头像、悬浮窗

## 偏好设置

### 界面语言

Eidolon 支持 **简体中文** 和 **English** 两种界面语言。

1. 进入 **设置 → 偏好 → 语言**
2. 从下拉菜单选择语言
3. 界面会自动切换，无需重启

### 主聊天模型 <span class="tier-badge tier-genesis">Genesis</span>

Genesis 用户可以自由切换主聊天使用的 AI 模型：

| 模型 | 特点 |
|------|------|
| Gemini 3.1 Flash Lite | 轻量快速，适合日常闲聊 |
| Gemini 3.5 Flash | 平衡性能与质量（默认） |
| Claude Opus 4.7 (1M) | 最强推理能力，超长上下文 |
| Claude Haiku 4.5 | 快速响应，性价比高 |

:::info 订阅要求
自由切换主聊天模型是 Genesis 等级的专属特权。其他等级使用系统默认模型。
:::

### Gemini 思维强度

控制 Gemini 模型回复前的思考深度：

| 等级 | 效果 |
|------|------|
| minimal | 最快响应，适合简单对话 |
| low | 轻微思考，平衡速度和质量 |
| medium | 默认等级，适合大多数场景 |
| high | 深度推理，复杂问题首选 |

等级越高推理质量越好，但响应更慢、消耗更多额度。仅对 Gemini 模型生效。

### 子代理（AI 代理）<span class="tier-badge tier-genesis">Genesis</span>

开启后，AI 子代理可以执行复杂多步任务，如终端命令、网页导航、桌面自动化。详见 [AI 代理](/features/agent)。

### 性别

设置你的性别，帮助 AI 更好地理解你的身份和交流偏好。可随时修改。

### 回复停顿

默认开启。AI 回复时采用分句间隔渲染，模拟自然的"打字"节奏。关闭后，分句渲染间隔缩短，消息显示更快。

### 主动回复延迟

当 AI 有主动消息（如提醒、关心）时，控制延迟发送的时间范围：

- **最短延迟**：最快多少秒后发送（默认 10 秒）
- **最长延迟**：最慢多少秒后发送（默认 60 秒）

适当调整可以让 AI 的主动消息更自然，不会秒回也不会等太久。

### 开机自启动（桌面端）

- **开机自启动**：系统启动时自动运行 Eidolon
- **启动时最小化**：自启动时以最小化方式运行，不打扰开机流程

### 桌面小组件（桌面端）

开启后，在桌面上以悬浮窗形式显示总结、待办、习惯和心情小组件，随时可见。详见 [生活动态与小组件](/features/life)。

### 专注时桌面伪全屏（桌面端）

进入专注模式时，窗口自动扩展为伪全屏，减少干扰。详见 [专注模式](/features/focus-timer)。

### 视频通话进入半身（桌面端）

视频通话时，AI 角色切换为半身模式并使用默认动作。表情、口型和鼠标跟随仍正常工作。默认开启。

### 60 分钟视频通话自动挂断

默认开启。视频通话达到 60 分钟时弹出提醒，5 分钟后自动挂断，防止忘记结束通话导致额度浪费。详见 [视频通话](/features/video-call)。

### 隐私部位渲染保护

默认开启。当摄像头视角靠近敏感区域时，AI 角色自动启用虚化与抖动保护。

### 表情参考图

AI 生成表情包时需要一张参考图来确定风格：

- **默认**：自动从当前 VRM 模型截图生成
- **自定义**：开启「使用自定义参考图」后，上传你自己的参考图

详见 [表情包与贴纸](/features/emoji-sticker)。

### 悬浮窗大小倍率（桌面端）

调整桌面悬浮窗角色的大小，范围 50% - 200%，默认 100%。

### Live2D 模型缩放

调整 Live2D 模型的显示大小，范围 50% - 200%，默认 100%。

## 危险区域

设置页面底部的「危险区域」包含一些不可逆操作：

| 操作 | 说明 |
|------|------|
| 清除本地缓存 | 清除本地缓存的消息和数据，云端数据不受影响 |
| 重置所有设置 | 将所有设置恢复为默认值 |

:::caution
危险区域的操作不可撤销，请谨慎操作。
:::

## 小贴士

- 大部分设置修改后立即生效，无需重启
- 设置会自动同步到云端，在不同设备上保持一致
- 如果设置异常，可以在「危险区域」中重置所有设置
