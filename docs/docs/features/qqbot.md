# QQ 机器人

Eidolon 支持接入 QQ 开放平台，让 AI 化身为 QQ 机器人，在 QQ 频道或群聊中自动回复消息。

---

## 启用 QQ 机器人

1. 前往 [QQ 开放平台](https://q.qq.com/) 注册并创建一个机器人应用
2. 获取机器人的 **AppID** 和 **AppSecret**
3. 在 Eidolon 中进入 **设置 → QQ 机器人**
4. 填写 AppID 和 AppSecret
5. 开启启用开关
6. 点击保存

---

## 配置说明

| 字段 | 说明 | 获取方式 |
|------|------|----------|
| AppID | 机器人的应用 ID | QQ 开放平台创建应用后获取 |
| AppSecret | 机器人的应用密钥 | QQ 开放平台应用详情页 |
| 启用 | 是否启用 QQ 机器人 | 开关 |

---

## 状态说明

| 状态 | 含义 |
|------|------|
| 运行中 · 正在监听 | 已连接腾讯网关，AI 在 QQ 中自动回复 |
| 未连接 | 需要填写凭据并启用 |

---

## 工作方式

启用后：

1. QQ 用户在频道或群聊中 @你的机器人
2. 消息转发到 Eidolon AI
3. AI 生成回复
4. 回复通过 QQ 机器人发送

---

## 安全提示

- AppSecret 是敏感信息，不要泄露给他人
- 建议定期更换 AppSecret
- 如果怀疑密钥泄露，立即在 QQ 开放平台重置

---

## 常见问题

### 机器人无法连接？
- 检查 AppID 和 AppSecret 是否正确
- 确认网络连接正常
- 确认 QQ 开放平台应用审核已通过

### 机器人不回复？
- 确认用户是 @了机器人（不是普通消息）
- 检查 AI 服务是否正常运行
- 查看设置页面机器人状态
