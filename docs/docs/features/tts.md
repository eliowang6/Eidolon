# TTS 语音设置

Eidolon 的 TTS（文本转语音）功能让 AI 用自然的语音回复你。你可以调整语音的情感强度，甚至上传自己的声音样本让 AI 用你的声音说话。

---

## 语音情感强度

AI 说话时的情感表现力可以调节：

1. 进入 **设置 → TTS**
2. 找到 **情感强度** 滑块
3. 拖动滑块调整强度

| 强度 | 效果 |
|------|------|
| 低 | 平稳、克制的语气 |
| 中 | 自然、适中的情感 |
| 高 | 丰富、生动的情感表达 |

## 参考音频

你可以上传一段参考音频，让 AI 的语音更接近你想要的声音风格。

### 上传参考音频

1. 进入 **设置 → TTS**
2. 点击 **上传参考音频** 按钮
3. 选择音频文件（建议 10-30 秒的清晰语音）
4. 等待上传和处理完成

### 参考音频要求

- 音频时长：建议 10-30 秒
- 内容：清晰的人声录音
- 格式：常见音频格式（WAV、MP3 等）

### 查看当前参考音频

设置页面会显示当前参考音频的信息：

- 是否已上传
- 文件大小
- 音频时长
- 上传时间

## 声音复刻（Genesis 专属）

<span class="tier-badge tier-genesis">Genesis</span>

Genesis 订阅用户可以使用 **声音复刻** 功能，让 AI 在视频通话中用你自己的声音说话。

### 使用方式

1. 上传 TTS 参考音频（见上文）
2. 系统会自动创建你的声音复刻
3. 在 Omni 模式的视频通话中，AI 会用你的声音说话

### 限制

- 每天最多上传 **1 次** 参考音频
- 删除音频后上传次数不会重置
- 声音复刻仅在 Omni 视频通话模式下生效

:::caution 声音复刻伦理
声音复刻功能仅限复刻你自己的声音。请勿上传他人的声音样本。滥用此功能可能导致账号被封禁。
:::

## 常见问题

### AI 语音没有感情？
- 尝试调高情感强度滑块
- 确认当前订阅等级支持情感 TTS

### 上传参考音频失败？
- 检查音频文件格式和大小
- 确认音频内容是清晰的人声
- 注意每日上传次数限制

### 声音复刻不像我的声音？
- 上传更清晰、更长的语音样本
- 尽量在安静环境中录制
- 避免背景噪音和其他人声
