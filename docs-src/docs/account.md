# 账号管理

Eidolon 使用简洁的用户名 + 密码认证体系，无需邮箱验证，注册即可使用。

---

## 注册账号

1. 打开 Eidolon，在登录页面点击 **「注册」** 标签
2. 填写注册信息：

| 字段 | 要求 | 说明 |
|------|------|------|
| 用户名 | 3-64 位英文/数字/下划线/连字符 | 用于登录，不可修改 |
| 昵称 | 任意文字 | AI 称呼你时使用的名字 |
| 密码 | 至少 8 位 | 建议包含字母和数字 |
| 确认密码 | 与密码一致 | 防止输入错误 |
| 邀请码 | 内测期间必填 | 从社区群获取 |
| 性别 | 男/女 | 帮助 AI 更好地理解你 |

3. 点击 **「创建账号并进入」**，注册成功后自动登录

:::info 关于邀请码
Eidolon 目前处于内测阶段，注册需要邀请码。邀请码由社区群主或 Up 主发放，加入官方社区即可获取。
:::

---

## 登录

1. 打开 Eidolon，默认显示登录页面
2. 输入用户名和密码
3. 点击 **「登录并进入」**

登录后，系统会自动同步你的历史对话、记忆和个性化设置。

---

## 修改密码

1. 点击右上角标题栏的用户菜单
2. 选择 **「修改密码」**
3. 输入当前密码和新密码
4. 点击 **「确认修改」**

:::tip 安全建议
- 不要使用与其他网站相同的密码
- 密码长度建议 12 位以上
- 定期更换密码
:::

---

## 退出登录

1. 点击右上角标题栏的用户菜单
2. 选择 **「退出」**
3. 确认退出

退出后，本地缓存的消息会被清除，但云端数据不受影响。重新登录后会自动恢复。

---

## 切换账号

Eidolon 支持在同一设备上切换不同账号：

1. 先退出当前账号
2. 在登录页面输入另一个账号的用户名和密码
3. 登录即可

每个账号拥有独立的对话空间、记忆和设置。切换账号后，AI 会以对应账号的身份与你交流。

---

## 数据安全

- 你的对话和记忆存储在云端服务器，使用加密传输
- 本地缓存仅在登录状态下可用
- 退出登录会清除本地缓存
- 同一账号在不同设备上登录，数据会自动同步
