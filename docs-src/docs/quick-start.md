# 快速上手

欢迎使用 Eidolon！这是一份面向零基础用户的入门指南，帮助你从安装到第一次对话，快速体验 AI 伴侣的魅力。

---

## 第一步：下载安装

Eidolon 支持 **Windows 桌面端**、**Android 手机端** 和 **网页端** 三种使用方式。

### Windows 桌面端

1. 前往 [Eidolon 官网](https://eidolon.ai) 或项目 [GitHub Releases](https://github.com/instarmony/eidolon/releases) 页面
2. 下载最新版本的 `.msi` 安装包
3. 双击安装包，按照向导完成安装
4. 安装完成后，桌面会出现 Eidolon 图标，双击即可启动

### Android 手机端

1. 在 GitHub Releases 页面下载 `.apk` 文件
2. 在手机上打开下载的 APK 文件
3. 如提示"未知来源"，请在设置中允许安装
4. 安装完成后，在应用列表中找到 Eidolon 打开

### 网页端

直接在浏览器中访问 Eidolon 网页地址即可使用，无需安装任何软件。

:::tip 推荐
桌面端体验最完整，支持悬浮窗、桌宠模式、开机自启动等独有功能。条件允许的话，推荐优先使用桌面端。
:::

---

## 第二步：注册账号

首次打开 Eidolon，你会看到登录页面。

1. 点击 **「注册」** 标签页
2. 填写以下信息：
   - **用户名**：3-64 位英文、数字、下划线或连字符（如 `myname_2024`）
   - **昵称**：AI 会用这个名字称呼你（如 `小明`）
   - **密码**：至少 8 位
   - **确认密码**：再次输入密码
   - **邀请码**：内测期间需要邀请码才能注册（如 `ABCD-EFGH-JKLM`）
   - **性别**：选择男或女
3. 点击 **「创建账号并进入」**

注册成功后会自动登录，进入 Eidolon 主界面。

:::info 邀请码从哪来？
内测期间，邀请码由群主或 Up 主发放。加入社区群即可获取。
:::

---

## 第三步：认识主界面

登录后你会看到 Eidolon 的 **「今天」** 主页，这是你每天的起点：

| 区域 | 说明 |
|------|------|
| **角色模型** | 页面中央的 3D 角色，会根据对话做出表情和动作 |
| **今日概览** | 显示当前订阅等级、主题、消息数等信息 |
| **待办事项** | 展示进行中的任务 |
| **心情记录** | 快速记录当前心情 |
| **导航栏** | 底部（手机）或侧边（桌面）的导航按钮 |

### 导航说明

| 导航项 | 功能 |
|--------|------|
| **今天** | 每日主页，概览和快捷入口 |
| **聊天** | 与 AI 的对话界面 |
| **剧场** | 沉浸式互动剧情 |
| **记忆** | 查看与 AI 的共同回忆 |
| **设置** | 个性化配置 |

---

## 第四步：开始第一次对话

1. 点击主页的 **「进入聊天」** 按钮，或点击导航栏的 **「聊天」**
2. 在底部的输入框中输入你想说的话
3. 点击发送按钮或按回车键
4. AI 会回复你的消息，角色也会做出相应的表情和动作

### 你可以试试这样说：

- 「你好！我是新来的，请多关照」
- 「今天天气怎么样？」
- 「帮我写一段自我介绍」
- 「给我讲个笑话吧」

:::tip 对话技巧
Eidolon 的 AI 拥有长期记忆，它会记住你说过的重要事情。越真诚地交流，AI 就越了解你。
:::

## 第五步：探索更多功能

完成第一次对话后，你可以继续探索这些核心功能：

- 🎙️ **语音通话**：在聊天输入框点击麦克风图标，和 AI 语音对话
- 📹 **视频通话**：点击摄像头图标，开启面对面的视频陪伴
- ✅ **待办管理**：让 AI 帮你创建待办事项和习惯打卡
- 🎭 **小剧场**：进入沉浸式互动剧情，体验不同故事
- 🎨 **画图**：让 AI 根据你的描述生成图片
- 😊 **表情包**：搜索并发送有趣的表情包

每个功能的详细用法，请参考左侧 **「功能详解」** 中的对应章节。

## 常见问题

### 启动后看不到角色模型？
角色模型需要加载时间，请耐心等待几秒。如果长时间不显示，检查网络连接是否正常。

### AI 不回复消息？
- 确认网络连接正常
- 检查订阅额度是否已用完（在设置中查看）
- 尝试刷新页面或重启应用

### 忘记密码怎么办？
目前请联系管理员重置密码。未来版本将支持自助找回。
