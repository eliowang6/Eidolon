# MCP 工具扩展

MCP（Model Context Protocol，模型上下文协议）是 Eidolon 提供的工具扩展机制。通过配置 MCP 服务器，你可以让 AI 获得额外的能力，比如访问数据库、调用外部 API 等。

:::info 面向高级用户
MCP 配置需要一定的技术基础。如果你不了解 JSON 配置和命令行，可以跳过此章节。
:::

---

## 什么是 MCP？

MCP 是一种标准化的协议，让 AI 能够调用外部工具。你可以把它理解为给 AI 安装"插件"：

- 配置一个 MCP 服务器 = 给 AI 添加一个新能力
- AI 在对话中自动判断何时调用这些工具
- 工具执行结果会返回到对话中

---

## 配置 MCP

1. 进入 **设置 → MCP**
2. 在 JSON 编辑器中输入 MCP 配置
3. 点击 **保存**
4. 点击 **启动** 运行配置的服务器

### 配置格式

```json
{
  "mcpServers": {
    "server-name": {
      "command": "可执行文件路径",
      "args": ["参数1", "参数2"],
      "env": {
        "环境变量名": "值"
      }
    }
  }
}
```

### 配置示例

```json
{
  "mcpServers": {
    "my-search": {
      "command": "npx",
      "args": ["-y", "@example/mcp-search"],
      "env": {
        "API_KEY": "your-api-key"
      }
    }
  }
}
```

---

## 管理 MCP 服务器

| 操作 | 说明 |
|------|------|
| 保存配置 | 保存 JSON 配置到本地 |
| 启动服务器 | 运行配置中的所有 MCP 服务器 |
| 停止服务器 | 停止正在运行的 MCP 服务器 |
| 查看状态 | 查看各服务器的运行状态 |

---

## 安全提示

:::warning
- MCP 服务器在你的本地环境中运行，请只配置你信任的服务器
- 不要在配置中暴露敏感信息（如 API 密钥）
- 环境变量中的密钥仅存储在本地，不会上传到服务器
:::

## 常见问题

### MCP 服务器启动失败？
- 检查 `command` 路径是否正确
- 确认 `args` 参数是否正确
- 查看环境变量是否设置完整

### AI 不调用 MCP 工具？
- 确认服务器已启动
- 尝试在对话中明确提示 AI 使用特定工具
- 检查工具描述是否清晰
