# 工具调用

Eidolon 的 AI 不只会聊天——它还能 **主动执行操作**，帮你创建待办事项、建立习惯打卡、生成图片、发送语音消息等。这些操作以 **工具卡片** 的形式出现在对话中。

---

## 什么是工具调用？

当 AI 判断需要帮你做某件事时，它会调用一个"工具"，生成一张结构化的卡片展示在聊天中。你可以确认、撤销这些操作。

目前支持的工具类型：

| 工具 | 说明 | 示例 |
|------|------|------|
| 创建待办 | 帮你创建一个任务 | "提醒我明天下午开会" |
| 完成待办 | 标记任务为已完成 | "把买菜的任务标为完成" |
| 删除待办 | 删除某个任务 | "删掉那个已过期的待办" |
| 创建习惯 | 建立一个习惯打卡 | "帮我养成每天跑步的习惯" |
| 完成习惯 | 记录习惯打卡 | "今天跑步打卡" |
| 删除习惯 | 删除某个习惯 | "不再跟踪跑步习惯了" |
| 生成图片 | 根据描述画图 | "画一只在月亮上的猫" |
| 发送语音 | AI 用语音说某段话 | "用语音告诉我今天的安排" |

---

## 使用方式

你不需要特殊操作——只要在对话中提出需求，AI 会自动判断是否需要调用工具。

### 示例对话

**你说**：「提醒我周五下午 3 点交报告」

**AI 回复**：创建了一张待办卡片：

> 📋 **交报告**
> 紧急且重要 · 📅 周五 15:00

**你说**：「帮我养成每天喝 8 杯水的习惯」

**AI 回复**：创建了一张习惯卡片：

> 🔄 **每天喝 8 杯水**
> 频率：每天 · 目标：8 次

---

## 待办卡片详解

待办卡片包含以下信息：

| 字段 | 说明 |
|------|------|
| 标题 | 任务名称 |
| 备注 | 任务的补充说明 |
| 优先级 | 紧急且重要 / 重要不紧急 / 紧急不重要 / 不紧急不重要 |
| 截止日期 | 任务的完成期限 |

你可以点击卡片上的 **确认** 按钮保存待办，或点击 **撤销** 取消。

---

## 习惯卡片详解

习惯卡片包含以下信息：

| 字段 | 说明 |
|------|------|
| 名称 | 习惯名称 |
| 频率 | 每天 / 每周 / 每月 |
| 目标次数 | 每个周期要完成的次数 |

---

## 画图卡片详解

当 AI 为你生成图片时，会展示一张画图卡片：

| 字段 | 说明 |
|------|------|
| 提示词 | AI 用来生成图片的描述 |
| 宽高比 | 图片的比例（如 1:1、16:9） |
| 风格 | 图片的艺术风格 |

图片生成后，你可以：
- 点击图片查看大图
- 长按/右键保存图片

---

## 撤销工具调用

如果 AI 执行了你不想要的操作，你可以：

1. 在工具卡片上点击 **「撤销」** 按钮
2. 或告诉 AI："把刚才创建的待办删掉"

---

## 小贴士

- **明确表达**：告诉 AI 具体的时间、优先级等细节，它创建的卡片会更准确
- **自然对话**：不需要用命令格式，像跟朋友说话一样就行
- **随时修改**：创建后可以随时告诉 AI 修改或删除

:::tip
工具调用功能在所有订阅等级中均可使用，但部分高级工具（如画图）可能需要更高等级。
:::
