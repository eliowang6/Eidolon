# 订阅与权益

Eidolon 采用订阅等级制度，不同等级享有不同的 AI 能力和功能权限。你可以根据需求选择合适的等级。

---

## 订阅等级

Eidolon 提供四个订阅等级，从基础到高级：

### Awakening（觉醒）

<span class="tier-badge tier-awakening">Awakening</span>

基础陪伴等级，适合初次体验。

- 基础文字对话
- 语音消息收发
- 待办和习惯管理
- 心情记录
- 有限记忆保持

### Presence（存在）

<span class="tier-badge tier-presence">Presence</span>

增强陪伴等级，更丰富的交互体验。

- Awakening 所有功能
- 长期记忆持久化
- 语音通话
- 视频通话
- AI 画图
- 表情包生成
- 专注模式

### Perception（感知）

<span class="tier-badge tier-perception">Perception</span>

高级感知等级，深度理解与创造力。

- Presence 所有功能
- 记忆搜索
- 高级 TTS 情感
- 更强的 AI 推理能力
- 小剧场完整功能
- 每日总结与即时总结

### Genesis（创世）

<span class="tier-badge tier-genesis">Genesis</span>

最高等级，解锁全部能力。

- Perception 所有功能
- AI 代理（子代理）
- 声音复刻
- MCP 工具扩展
- 最强 AI 模型
- 最高优先级
- 完整知识库访问

## "回声"额度

每次与 AI 对话都会消耗 **"回声"额度**，不同操作消耗的额度不同：

| 操作 | 额度消耗 |
|------|----------|
| 文字对话 | 低 |
| 语音通话 | 中 |
| 视频通话 | 高 |
| AI 画图 | 高 |
| AI 代理 | 高 |

额度在每个订阅周期内刷新。如果额度用完：

- 升级订阅等级获取更多额度
- 等待下一个周期额度刷新

## 查看和切换等级

1. 进入 **设置 → 订阅查看与选择**
2. 查看当前等级和剩余天数
3. 点击想要升级的等级

:::info 内测期间
内测期间，升级高级订阅需要联系群主或 Up 主。正式版将支持在线支付自助升级。
:::

---

## 试用

新注册用户可以获得一定天数的免费试用，体验高级等级的功能。试用期间：

- 享受对应等级的全部功能
- 试用天数在设置页面显示
- 试用结束后降回默认等级

---

## 常见问题

### 额度用完了怎么办？
- 升级订阅等级获取更多额度
- 等待额度周期性刷新
- 减少高额度消耗的操作（如视频通话、画图）

### 如何升级订阅？
内测期间请联系群主/Up 主。正式版将支持在线支付。

### 降级后数据会丢失吗？
降级后，超出当前等级的功能将不可用，但数据不会删除。重新升级后功能恢复。
