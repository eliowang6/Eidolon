# 小剧场

小剧场是 Eidolon 的沉浸式互动剧情功能。你可以创建或进入一个故事世界，与 AI 共同演绎一段独特的冒险。

---

## 什么是小剧场？

小剧场是一个 **互动叙事** 系统：

- 你是故事的主角，AI 是故事的讲述者和世界的主宰
- 你的每个选择都会影响故事走向
- AI 会根据你的设定生成独特的剧情
- 故事中可以包含战斗、解谜、情感、探索等元素

---

## 创建新剧本

1. 点击导航栏的 **「剧场」**
2. 点击 **「创建新剧本」**
3. 你可以选择 **手动配置** 或 **随机生成**

### 随机生成

点击随机生成，系统会自动创建一个完整的剧本设定，包括世界观、角色、剧情走向等。适合想快速开始的用户。

### 手动配置

你可以精细调整剧本的每一个细节：

#### 世界设定

| 设定项 | 说明 | 示例 |
|--------|------|------|
| 主类型 | 故事的主要类型 | 奇幻、科幻、都市、历史 |
| 子类型 | 故事的次要类型 | 悬疑、浪漫、冒险 |
| 世界框架 | 世界的底层规则 | 魔法世界、赛博朋克、现实世界 |
| 世界法则 | 世界的特殊规则 | 魔法需要代价、AI 有意识 |
| 基调 | 故事的氛围 | 黑暗、轻松、史诗 |
| 节奏 | 故事推进速度 | 紧凑、舒缓、张弛有度 |

#### 角色设定

| 设定项 | 说明 |
|--------|------|
| 主角名字 | 你在故事中的名字 |
| 主角身份 | 你的角色定位 |
| 主角目标 | 你想达成什么 |
| 主角秘密 | 你隐藏的事情 |
| 主角弱点 | 你的软肋 |
| AI 角色名 | AI 扮演的角色名 |
| AI 角色身份 | AI 角色的定位 |
| AI 角色关系 | AI 角色与你的关系 |

#### 剧情设定

| 设定项 | 说明 |
|--------|------|
| 剧情焦点 | 世界/机制/关系/均衡 |
| 剧情方向 | 悬疑/挣扎/情感/成长 |
| 任务模式 | 无/柔和/明确 |
| 系统风格 | 无/温和/调侃/讽刺/严格 |
| 开场情境 | 故事开始时的场景 |

## 进入剧本

创建或选择一个剧本后，进入剧本对话界面：

- 你输入行动或对话
- AI 描述场景变化和 NPC 反应
- 故事持续推进

### 行动选项

AI 有时会提供行动选项供你选择：

| 选项类型 | 标记 | 含义 |
|----------|------|------|
| 积极 | 绿色 | 正面推进的选择 |
| 意外 | 蓝色 | 出乎意料的发展 |
| 消极 | 红色 | 可能带来麻烦 |
| 跳过 | 灰色 | 跳过当前场景 |
| 充能 | 金色 | 积蓄力量的选择 |

你也可以不选预设选项，自由输入任何行动。

---

## 剧本管理

### 剧本列表

在剧场页面可以看到所有剧本：

- 按最近活动排序
- 显示剧本标题、状态和最后消息时间
- 点击进入继续剧情

### 分支剧本

你可以从现有剧本创建分支：

- 在剧本菜单中选择 **「创建分支」**
- 输入新剧本的标题
- 分支会继承原剧本的设定，但剧情独立发展

### 编辑剧本

随时可以修改剧本设定，调整世界观、角色和剧情参数。

## 剧本中的图片

剧本进行中，AI 可能会根据剧情生成场景图片，增强沉浸感。
