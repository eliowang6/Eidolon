# AI 画图

Eidolon 的 AI 画图功能让你用文字描述就能生成图片。无论是可爱的插画、精美的风景还是创意设计，AI 都能帮你画出来。

---

## 如何画图

### 通过对话请求

直接在聊天中告诉 AI 你想画什么：

- 「画一只在月亮上睡觉的猫」
- 「帮我画一张赛博朋克风格的城市夜景」
- 「生成一张 16:9 的日落海滩图片」

AI 会调用画图工具，生成图片后展示在聊天中。

### 通过工具卡片

AI 生成图片时会显示画图卡片，包含：

| 信息 | 说明 |
|------|------|
| 提示词 | AI 用于生成图片的描述 |
| 宽高比 | 图片的比例 |
| 风格 | 图片的艺术风格 |

---

## 画图参数

### 宽高比

你可以指定图片的比例：

| 比例 | 适合场景 |
|------|----------|
| 1:1 | 头像、表情包、正方形构图 |
| 16:9 | 风景、壁纸、横幅 |
| 9:16 | 手机壁纸、竖版构图 |
| 4:3 | 传统照片比例 |
| 3:4 | 肖像比例 |

### 风格

你可以指定图片的艺术风格：

- 「水彩风格」
- 「油画风格」
- 「动漫风格」
- 「写实风格」
- 「像素风格」
- 等等...

### 参考图

你还可以发送图片作为参考，让 AI 基于参考图生成新图：

1. 先发送一张参考图片
2. 然后说「参考这张图，画一个类似风格的...」

---

## 查看和保存图片

- 点击聊天中的图片可以查看大图
- 在大图查看器中可以保存图片到本地
- 图片也会保存在对话记录中

---

## 使用技巧

- **描述越具体，效果越好**：「一只橘猫蜷在蓝色月亮上睡觉，背景是星空」比「猫」效果好得多
- **指定风格**：告诉 AI 你想要什么风格，避免随机
- **利用参考图**：有参考图时生成效果更可控
- **多次尝试**：不满意可以让 AI 重新生成

:::tip
画图功能消耗的"回声"额度比普通对话多，请合理使用。
:::
