# 闹钟提醒

Eidolon 的闹钟功能让 AI 在指定时间提醒你重要事项。不同于普通闹钟，AI 会以对话的方式温柔地叫醒你或提醒你。

---

## 创建闹钟

1. 进入 **设置 → 闹钟**
2. 点击 **「添加闹钟」**
3. 填写闹钟信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 标题 | 闹钟名称 | 起床 |
| 描述 | 详细说明（可选） | 该准备出门了 |
| 时间 | 触发时间 | 07:30 |
| 重复 | 重复方式 | 单次/每天/每周/每月 |

4. 点击保存

---

## 重复方式

| 选项 | 说明 |
|------|------|
| 单次 | 只响一次，响后自动关闭 |
| 每天 | 每天同一时间响铃 |
| 每周 | 每周同一时间响铃 |
| 每月 | 每月同一时间响铃 |

---

## 管理闹钟

### 查看闹钟列表

在 **设置 → 闹钟** 中查看所有闹钟，每个闹钟显示：

- 标题和描述
- 触发时间
- 重复方式
- 启用/禁用状态

### 启用/禁用

- 点击闹钟旁的开关可以临时禁用闹钟，不删除
- 禁用后闹钟不会触发，但可以随时重新启用

### 编辑闹钟

点击闹钟条目进入编辑模式，修改任意字段后保存。

### 删除闹钟

在闹钟列表中删除不需要的闹钟。

---

## 闹钟触发

当闹钟触发时：

1. 系统发送通知提醒（桌面端/手机端）
2. AI 会在对话中主动提醒你
3. 触发后单次闹钟会自动标记为已触发

---

## 通知权限

闹钟功能需要通知权限才能正常工作：

- **桌面端**：首次使用时系统会请求通知权限
- **Android**：确保 Eidolon 的通知权限已开启
- **网页端**：浏览器需要允许通知

如果闹钟没有触发，请检查通知权限是否已授予。

---

## 小贴士

- 利用重复闹钟建立日常规律（如每天 7:30 起床）
- 给闹钟加上描述，AI 提醒时会更有针对性
- 配合待办功能使用，不错过任何重要事项
