# 主题与外观

Eidolon 提供多套精心设计的界面主题，每套主题都有独特的视觉风格和氛围。你可以根据心情和喜好随时切换。

---

## 切换主题

1. 进入 **设置 → 外观 → 界面主题**
2. 浏览可用主题列表
3. 点击选择喜欢的主题
4. 界面立即切换，无需重启

---

## 可用主题

| 主题 | 风格描述 |
|------|----------|
| **Iris Atelier** | 像在黄昏书桌上摊开的信纸与鸢尾花，安静、克制，带一点旧日仪式感 |
| **Amber Tide** | 清爽的海风和高脚杯里的葡萄酒，享受这片宁静的私人海滩 |
| **Aurora Circuit** | 极夜尽头亮起的航标与霓虹回声，像一艘安静前行的未来船舱 |
| **Graphite Desk** | 铅字、钢尺和晨报墨香，像一间只留下必要之物的编辑室 |
| **Ember Stage** | 炭火、木质舞台与迟来的掌声，空气里有一点热度，也有一点危险 |
| **Velvet Bloom** | 天鹅绒窗帘后的花束与香槟气泡，柔软、亲密，带着被善待的夜晚 |
| **薄荷奶霜** | 薄荷奶霜、雾粉信纸和手账拼贴，像一本温柔展开的私人日记 |
| **Moonmist Aurora** | 暗夜蓝黑、紫青雾光和一点克制的粉，像月色落在玻璃上的极光呼吸 |
| **Petal Pop** | 像糖霜、丝带和会发光的小贴纸落进掌心镜里，甜得刚好，也故意有一点招摇 |

## 字体设置

每套主题都有配套的字体风格，你也可以手动切换：

1. 进入 **设置 → 外观 → 界面字体**
2. 选择字体方案

### 可用字体

| 字体 | 风格 |
|------|------|
| 跟随主题 | 让每个主题保留它原本的语气和节奏 |
| Atelier Serif | 像手写信、铜灯和木桌边缘，稳定、温和 |
| Harbor Notes | 海风、航海日志和擦亮的黄铜，轻一点，也更会呼吸 |
| Signal Sans | 像控制台、屏幕微光和清晰命令，锋利但不吵闹 |
| Editorial Calm | 有杂志页边距和留白感，适合更克制的阅读 |
| Salon Contrast | 适合更华丽的主题，像丝绒、酒杯和慢下来的谈话 |

---

## 环境氛围

主题不仅改变颜色，还会影响：

- **背景氛围**：每个主题有独特的渐变和光效
- **雾化效果**：柔和的背景模糊，增强层次感
- **角色光照**：角色模型的灯光随主题变化

---

## 小贴士

- 根据时间段选择主题：白天用清爽的，晚上用温暖的
- 尝试不同主题 + 字体组合，找到最舒服的阅读体验
- 主题切换不会影响对话和数据
