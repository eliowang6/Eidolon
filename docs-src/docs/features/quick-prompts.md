# 快捷提问

快捷提问是 Eidolon 提供的预设对话模板，一键即可发起常见场景的对话，无需思考怎么开口。

---

## 使用快捷提问

1. 在聊天输入框上方，找到 **「快捷提问」** 区域
2. 点击任意快捷按钮
3. AI 会自动发起对应场景的对话

---

## 可用快捷提问

| 快捷提问 | 说明 | 示例对话 |
|----------|------|----------|
| 🎭 **小剧场** | 进入互动剧情模式 | 开启一段沉浸式故事 |
| 🍴 **吃什么** | 让 AI 推荐美食 | "你觉得我吃点什么好呢？" |
| 🗺️ **去哪玩** | 让 AI 推荐出行 | "帮我想想可以去哪玩" |
| 📝 **解答题目** | 拍照让 AI 解题 | "教教我怎么做这题"（需拍照） |
| 💬 **你问我答** | 互动问答游戏 | "来玩你问我答" |
| 🔍 **分析一下** | 拍照让 AI 分析 | "帮我分析一下图中这个"（需拍照） |
| 🧩 **脑筋急转弯** | 玩脑筋急转弯 | "来玩一局脑筋急转弯" |

---

## 拍照类快捷提问

**解答题目** 和 **分析一下** 需要拍照：

1. 点击快捷按钮后，会自动打开摄像头
2. 对准要拍摄的内容拍照
3. 照片自动发送给 AI
4. AI 会分析照片内容并回复

---

## 小贴士

- 不知道聊什么的时候，试试快捷提问
- 「吃什么」和「去哪玩」会根据你的偏好推荐
- 「你问我答」和「脑筋急转弯」适合休闲放松
- 「解答题目」是学习的好帮手
