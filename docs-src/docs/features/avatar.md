# 角色模型

Eidolon 的核心体验之一是 **3D 角色陪伴**。AI 伴侣以角色的形式出现在你的桌面上，会根据对话做出表情、动作和口型同步。

---

## 角色渲染模式

Eidolon 支持多种角色渲染模式：

| 模式 | 说明 | 特点 |
|------|------|------|
| **VRM** | 3D 角色模型 | 支持表情、动作、鼠标跟随 |
| **Live2D** | 2D 动画模型 | 更细腻的表情变化 |
| **GLB** | 通用 3D 模型 | 兼容性广 |

---

## 加载模型

### 选择模型

1. 在 **设置 → 外观 → 角色模型** 中点击 **「加载模型」**
2. 或在悬浮窗中点击 **「加载模型」** 按钮
3. 选择 VRM 或 Live2D 模型文件
4. 等待模型加载完成

### 模型选择器

模型选择器提供两种模式切换：

- **切换到 VRM**：使用 3D 模型
- **切换到 Live2D**：使用 2D 动画模型

---

## 角色互动

加载模型后，角色会：

| 行为 | 说明 |
|------|------|
| 表情变化 | 根据对话内容做出开心、悲伤等表情 |
| 动作播放 | 挥手、跳舞等动作 |
| 口型同步 | 说话时嘴巴会跟着动 |
| 鼠标跟随 | 角色的视线跟随你的鼠标（桌面端） |
| 听话状态 | 你说话时角色做出倾听的表情 |

---

## 头像设置

你可以为用户和 AI 设置头像：

1. 进入 **设置 → 外观 → 头像**
2. 分别点击 **用户头像** 和 **AI 头像** 的上传按钮
3. 选择图片文件上传
4. 上传成功后头像会同步到聊天、生活、我们等页面

### 头像说明

- 头像在聊天、生活动态和"我们"页面通用
- 可随时更换或恢复默认头像
- 支持常见图片格式（JPG、PNG、GIF）

---

## 悬浮窗模式（桌面端）

桌面端支持将角色以悬浮窗形式展示：

- 角色以小窗口悬浮在桌面最前方
- 可以随时看到角色的状态
- 悬浮窗大小可在设置中调整

### 调整悬浮窗大小

在 **设置 → 偏好 → 悬浮窗大小倍率** 中调整：

- 100% 为默认尺寸
- 可调整范围：50% - 200%

---

## 主页人物大小

在 **设置 → 偏好 → 主页人物大小比例** 中调整主页角色的显示大小：

- 100% 为默认尺寸
- 可调整范围：50% - 200%

---

## 隐私保护

Eidolon 默认开启 **隐私部位渲染保护**：

- 当视角靠近敏感区域时，角色会自动启用虚化与抖动保护
- 可在 **设置 → 偏好 → 隐私部位渲染保护** 中关闭

---

## 常见问题

### 模型加载失败？
- 检查模型文件格式是否正确（VRM/Live2D/GLB）
- 确认文件没有损坏
- 尝试重新加载

### 角色不说话/不动？
- 确认模型已加载成功
- 检查是否在对话中（AI 回复时角色才会动）
- 尝试发送一条消息触发角色反应
