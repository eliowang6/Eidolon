# 语音通话

语音通话让你像打电话一样和 AI 对话，无需打字，开口即聊。

---

## 发起语音通话

1. 在聊天页面，点击输入框上方的 **🎤 语音通话** 按钮
2. 等待连接建立（显示"正在呼叫..."）
3. 连接成功后，状态变为"通话中"
4. 直接对着麦克风说话，AI 就能听到并回复

---

## 通话中的操作

| 操作 | 说明 |
|------|------|
| 静音 | 点击静音按钮，AI 将听不到你的声音 |
| 解除静音 | 再次点击取消静音 |
| 免提 | 切换扬声器播放 |
| 挂断 | 点击红色挂断按钮结束通话 |

---

## 通话特点

- **实时对话**：你说完 AI 立刻回复，几乎没有延迟
- **语音识别**：你的话会被自动转为文字，显示在聊天记录中
- **语音合成**：AI 的回复会以自然语音读出
- **角色联动**：通话时角色模型会做出说话的口型和表情
- **记忆保存**：通话内容会保存到聊天记录和长期记忆中

---

## 语音通话记录

通话结束后，聊天记录中会出现一条通话记录卡片，包含：

- 通话类型（语音通话）
- 通话时长
- 通话中的对话转录

你可以随时回顾之前的通话内容。

---

## 常见问题

### 语音通话没有声音？
- 检查设备音量是否开启
- 检查麦克风权限是否已授予
- 尝试插拔耳机或切换免提模式

### AI 听不到我说话？
- 确认麦克风权限已开启
- 检查是否误触了静音按钮
- 尝试靠近麦克风说话
