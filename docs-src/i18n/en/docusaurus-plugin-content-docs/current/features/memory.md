# Long-Term Memory

Eidolon's AI has **long-term memory** — it automatically remembers important information you share and retains that understanding across sessions. The more you chat, the better it knows you.

---

## How Memory Works

1. **Auto-detection**: AI identifies worth-remembering information in conversations
2. **Storage**: Important info is saved to the long-term memory store
3. **Recall**: AI references memories in future conversations to understand you better
4. **Accumulation**: As you interact more, AI's understanding of you deepens

---

## What AI Remembers

| Type | Examples |
|------|----------|
| Personal info | Name, birthday, gender |
| Preferences | Favorite food, movie genres |
| Daily habits | Sleep schedule, exercise routine |
| Important events | Exam dates, travel plans |
| Relationship info | Friends' names, family situation |
| Emotional state | Recent mood changes |

---

## Viewing Memories

1. Click **"Memory"** in the navigation bar
2. Browse all information AI has remembered
3. Each memory entry shows:
   - What you said
   - AI's response
   - When it was recorded
   - Whether it includes images/voice

### Searching Memories

On the Memory page, you can search for specific content:

- Enter keywords to find related memories
- Browse memories by time
- View memories that include images or voice

---

## Memory & Subscriptions

Memory capabilities differ by subscription tier:

| Tier | Memory Persistence | Memory Search |
|------|-------------------|---------------|
| Awakening | Limited | ❌ |
| Presence | ✓ | ❌ |
| Perception | ✓ | ✓ |
| Genesis | ✓ | ✓ |

- **Memory Persistence**: Whether memories are retained after conversations end
- **Memory Search**: Whether you can search through historical memories

## Tips

- Proactively tell AI your important information to help it understand you better
- Periodically review the Memory page to confirm AI's remembered info is accurate
- If AI remembers something wrong, just tell it the correct info — it will update its memory
