# Smart Chat

Chat is the core feature of Eidolon. Talk to AI just like chatting with a friend. AI has long-term memory — it remembers what you share, and understands you better over time.

---

## Sending Messages

### Text Messages

1. Go to the **"Chat"** page
2. Tap the input box at the bottom
3. Type your message
4. Press Enter or click the send button

### Quote Reply

You can quote a previous message to reply to it:

1. Long-press (mobile) or right-click (desktop) the message you want to quote
2. Select **"Quote"**
3. A quote preview appears above the input box
4. Type your reply and send
5. Click the × on the quote preview to cancel

### Undo a Message

If you sent something you didn't mean to:

1. Long-press (mobile) or right-click (desktop) the message you just sent
2. Select **"Undo"**

:::tip
Undo only works for your own messages. AI has already received the content and cannot truly "forget" it.
:::

## Sending Images & Videos

### From Gallery

1. Click the **📎** attachment button on the left of the input box
2. Select **"Choose from Gallery"**
3. Pick the image or video to send
4. Send it

### Take a Photo

1. Click the **📷** camera button on the left of the input box
2. Aim at what you want to capture
3. Click the capture button
4. Choose to retake or send

:::info AI Image Understanding
AI can understand the images you send. You can share screenshots for analysis, scenery photos for descriptions, or problem photos for solutions.
:::

### Screen Capture/Record (Desktop)

Desktop users can capture or record their screen directly:

1. Click the **Screenshot** or **Screen Record** button in the input box
2. Select the screen area to capture
3. The capture is automatically attached and sent

---

## Sending Files

You can send document files to AI:

1. Click the attachment button on the left of the input box
2. Select the file to send
3. After sending, AI reads the file content and replies

---

## Emoji & Stickers

### Common Emoji

The emoji panel above the input box contains 40 curated emoji. Tap to insert.

### Search Emoji

1. Click the **Emoji** button in the input box
2. Enter a keyword in the search box (e.g. "happy", "cat")
3. The system searches for matching emoji packs
4. Tap an emoji to send it

### Custom Stickers

Upload your own images or GIFs as stickers:

1. Click **"Upload Sticker"** in the emoji panel
2. Select an image or GIF file (max 5MB, max 1024×1024)
3. After upload, it appears in your custom sticker panel

:::warning Custom Sticker Limits
- Single file max 5 MB
- Image dimensions max 1024×1024
- Maximum 50 custom stickers
:::

## Voice Messages

You can also send voice messages:

1. Click the **🎤** voice button in the input box
2. **Hold to speak**, release to send
3. Slide up to cancel recording

AI will understand your voice content and reply with both text and voice.

## AI's Responses

AI may respond in various formats:

| Type | Description |
|------|-------------|
| Text | The most common response format |
| Voice | AI reads out the reply with synthesized speech |
| Image | AI-generated images (e.g. via the drawing feature) |
| Emoji Pack | AI sends emoji stickers |
| Tool Card | Structured info cards for to-dos, habits, etc. |

---

## Conversation Memory

Eidolon's AI features **long-term memory**:

- AI automatically remembers important information from conversations
- Memory persists across sessions — even after closing and reopening the app, AI still remembers you
- You can view what AI remembers on the **"Memory"** page
- Memory supports search for easy回顾

:::tip Help AI Remember You
Tell AI about your preferences, habits, and important dates. For example: "I love watching movies on Friday nights", "My birthday is March 15th".
:::

| Status | Meaning |
|--------|---------|
| Sending | Message is being sent |
| Delivered | Message was successfully delivered |
| Failed | Sending encountered an issue — tap to retry |
