# Focus Mode

Focus Mode is Eidolon's Pomodoro timer feature, helping you enter deep work states. AI accompanies you while you focus and chats with you during breaks.

---

## Entering Focus Mode

1. On the **"Today"** home page, click the **"Focus Mode"** button
2. Select a focus profile
3. Start focusing

---

## Focus Profiles

Eidolon offers three focus profiles:

| Profile | Focus + Break | Best For |
|---------|---------------|----------|
| **Classic 25** | 25 min focus + 5 min break | Daily Pomodoro, steady start |
| **Sprint 40** | 40 min focus + 8 min break | Active tasks, longer focus |
| **Deep 50** | 50 min focus + 10 min break | Deep work, tasks needing immersion |

---

## Ambient Sounds

Choose background audio to help you concentrate during focus:

| Track | Effect |
|-------|--------|
| **Valley** | Natural valley sounds, peaceful and soothing |
| **Rain** | Rain sounds, classic white noise |
| **Creek** | Stream sounds, gentle flowing |
| **Silent** | No background sound |

---

## Focus Process

When Focus Mode is running:

1. **Focus phase**: Countdown in progress, ambient sounds playing
2. **Break phase**: Focus ends, break countdown begins
3. **Cycles**: Automatically alternates between focus and break per the profile

### Desktop Immersive Mode

Desktop supports **pseudo-fullscreen immersive mode**:

- Window automatically expands to fullscreen during focus
- Reduces distractions for better concentration
- Enable in **Settings → Preferences → Focus Desktop Pseudo-Fullscreen**

---

## AI Companionship

During Focus Mode, AI:

- Encourages you when you start focusing
- Chats casually during break times
- Records your focus duration for daily summaries

---

## Focus Records

Each focus session's duration is recorded. You can see in daily summaries:

- Total focus time today
- Number of completed Pomodoros
- Focus time distribution

---

## Tips

- Start with Classic 25, then try longer profiles once you're comfortable
- Choose ambient sounds that suit you for the best focus environment
- Actually rest during breaks — stand up, stretch, or chat with AI
