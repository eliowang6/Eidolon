# AI Image Generation

Eidolon's image generation feature lets you create images from text descriptions. Whether it's cute illustrations, beautiful landscapes, or creative designs, AI can draw it for you.

---

## How to Generate Images

### Via Conversation

Just tell AI what you want to see in the chat:

- "Draw a cat sleeping on the moon"
- "Generate a cyberpunk-style city nightscape in 16:9"
- "Create a sunset beach image"

AI invokes the drawing tool and displays the generated image in the chat.

### Via Tool Card

When AI generates an image, it shows a generation card with:

| Info | Description |
|------|-------------|
| Prompt | The description AI uses to generate the image |
| Aspect Ratio | Image proportions |
| Style | Artistic style of the image |

---

## Image Parameters

### Aspect Ratio

Specify the image proportions:

| Ratio | Best For |
|-------|---------|
| 1:1 | Avatars, stickers, square compositions |
| 16:9 | Landscapes, wallpapers, banners |
| 9:16 | Phone wallpapers, vertical compositions |
| 4:3 | Traditional photo ratio |
| 3:4 | Portrait ratio |

### Style

Specify an artistic style:

- "Watercolor style"
- "Oil painting style"
- "Anime style"
- "Realistic style"
- "Pixel art style"
- And more...

### Reference Images

Send an image as a reference for AI to base new generations on:

1. Send a reference image first
2. Then say "Based on this image, draw something in a similar style..."

---

## Viewing & Saving Images

- Click an image in the chat to view it full-size
- In the full-size viewer, save the image to your device
- Images are also saved in the conversation history

---

## Tips

- **More specific = better results**: "An orange cat curled up on a blue moon with a starry background" works much better than just "cat"
- **Specify a style**: Tell AI what style you want to avoid randomness
- **Use reference images**: Results are more controllable with reference images
- **Try multiple times**: If you're not satisfied, ask AI to regenerate

:::tip
Image generation consumes more "Echo" quota than regular conversations. Use it wisely.
:::
