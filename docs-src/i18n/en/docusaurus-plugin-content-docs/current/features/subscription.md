# Subscription & Benefits

Eidolon uses a subscription tier system where different tiers unlock different AI capabilities and feature access. Choose the tier that fits your needs.

---

## Subscription Tiers

Eidolon offers four tiers, from basic to premium:

### Awakening

<span class="tier-badge tier-awakening">Awakening</span>

The basic companionship tier, perfect for first-time users.

- Basic text conversation
- Voice message sending & receiving
- To-do and habit management
- Mood tracking
- Limited memory retention

### Presence

<span class="tier-badge tier-presence">Presence</span>

Enhanced companionship with richer interactions.

- All Awakening features
- Long-term memory persistence
- Voice calls
- Video calls
- AI image generation
- Emoji generation
- Focus Mode

### Perception

<span class="tier-badge tier-perception">Perception</span>

Advanced perception tier with deep understanding and creativity.

- All Presence features
- Memory search
- Advanced TTS emotion
- Stronger AI reasoning
- Full Theater features
- Daily summaries & instant summaries

### Genesis

<span class="tier-badge tier-genesis">Genesis</span>

The highest tier, unlocking all capabilities.

- All Perception features
- AI Agent (Sub-Agent)
- Voice cloning
- MCP tool extensions
- Most powerful AI model
- Highest priority
- Full knowledge base access

## "Echo" Quota

Every AI interaction consumes **"Echo"** quota. Different actions consume different amounts:

| Action | Quota Cost |
|--------|------------|
| Text Chat | Low |
| Voice Call | Medium |
| Video Call | High |
| AI Image Generation | High |
| AI Agent | High |

Quota refreshes each subscription cycle. When quota runs out:

- Upgrade your subscription for more quota
- Wait for the next cycle's quota refresh

---

## View & Switch Tiers

1. Go to **Settings → Subscription**
2. View your current tier and remaining days
3. Click the tier you want to upgrade to

:::info During Beta
During the beta period, upgrading to premium tiers requires contacting the community admin or content creator. The official release will support online payment for self-service upgrades.
:::

---

## Trial

New users receive a free trial period to experience premium tier features. During the trial:

- Enjoy all features of the corresponding tier
- Trial days remaining are shown in settings
- After the trial ends, you revert to the default tier

---

## Common Issues

### Quota used up?
- Upgrade your subscription tier for more quota
- Wait for quota to refresh cyclically
- Reduce high-quota actions (like video calls, image generation)

### How to upgrade?
During beta, contact the community admin/creator. The official release will support online payment.

### Will data be lost after downgrading?
Downgrading makes features above your current tier unavailable, but data is not deleted. Features restore upon re-upgrading.
