# Emoji & Stickers

Eidolon supports rich emoji and sticker features to make conversations more lively and fun. Search from a massive emoji library or upload your own exclusive stickers.

## Search Emoji Packs

Eidolon has built-in emoji search — enter a keyword to find matching emoji:

1. Click the **Emoji** button in the input box
2. Enter a keyword in the search box (e.g. "happy", "cat", "cheer")
3. The system searches for matching emoji packs
4. Tap an emoji to send it

### Search Tips

- Specific keywords work better: "laughing" is more precise than "laugh"
- Combine keywords: "cat angry"
- AI also auto-suggests emoji based on conversation context

## Custom Stickers

Upload your own images or GIFs as stickers to use anytime in chat.

### Upload Stickers

1. Click **"Upload Sticker"** in the emoji panel
2. Select an image or GIF file
3. Wait for upload to complete
4. Uploaded stickers appear in the custom sticker panel

### Sticker Limits

| Limit | Requirement |
|-------|-------------|
| File size | Max 5 MB |
| Image dimensions | Max 1024×1024 |
| Quantity | Max 50 custom stickers |
| Format | JPG, PNG, GIF |

### Managing Stickers

- Long-press/right-click a sticker in the custom panel to delete it
- Deleted stickers cannot be recovered — proceed with caution

---

## AI-Sent Emoji

AI also sends emoji during conversations:

- AI chooses appropriate emoji based on the conversation mood
- AI-generated emoji are based on your character model reference image
- You can customize the emoji reference image in settings

### Emoji Reference Image

AI needs a reference image when generating emoji to determine the style:

- **Default**: Automatically generated from the current VRM model screenshot
- **Custom**: Upload your own reference image in **Settings → Preferences → Use Custom Reference Image**

:::tip
Using a custom reference image lets AI generate emoji that better matches your desired style.
:::
