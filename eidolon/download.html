客户端下载与平台支持

目前仅支持 Windows 与 Android；macOS、iOS、Linux 和 Web 暂不支持。

Windows 桌面端

支持 Windows 10 / 11 (64位)。提供精美 3D 桌宠、打字互动模式与桌面自驱代办。

下载 Windows MSI 安装包

Android 移动端

支持 Android 10.0+。具备智能情境感知（位置、步数、通知摘要）、消息推送与随时随地的语音畅聊。
